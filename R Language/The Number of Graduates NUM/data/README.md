# File name structure

`-2023-autumn.csv`

```
-       :  prefix
2023    :  the first year of the current graduation year
-       :  separator
autumn  :  fall semester
.csv    :  file name extension
```

# Variables/Columns

1. бүрэлдэхүүн_сургуулийн_дугаар : Бүрэлдэхүүн,салбар сургуулийн дугаар
2. бүрэлдэхүүн_сургууль : Бүрэлдэхүүн,салбар сургуулийн нэр
3. хөтөлбөрийн_дугаар : Хөтөлбөрийн дугаар
4. хөтөлбөр : Хөтөлбөрийн нэр
5. зэрэг : Төгсгөж байгаа хөтөлбөрийн боловсролын зэрэг
6. төгсөгчийн_эцэг_эхийн_нэр : Төгсөгчийн эцэг/эхийн нэр
7. төгсөгчийн_өөрийн_нэр : Төгсөгчийн өөрийн нэр
8. дипломын_дугаар : Төгсөгчийн дипломын дугаар
9. төгссөн_жил : Төгсөгчийн төгссөн хичээлийн жил
10. төгссөн_улирал : Төгсөгчийн төгссөн хичээлийн жилийн улирал
